# 岔路 · 体验说明

面向第一次打开这个产品的作者或评审。全文按实际操作顺序写，不需要额外培训。

## 一句话

把你写好或读过的故事放进来，从一个"当初可以不一样"的关键决定开始，由你决定主角接下来做什么，走完 4～12 个回合后带走一段阶段回顾。

## 开始之前

拿到访问地址后：

- 页面顶部会显示当前模式：**本地假模型**或**真实模型**。
- 若出现访问码输入框，输入部署方提供的演示访问码即可；访问码只用于进入页面，不会进入你的故事内容。
- 你的进度保存在这台设备的浏览器里。换设备或清除浏览器数据后不会同步。

## 五分钟走完主路径

### 1. 放入原始故事（01 / 原始故事）

三种方式任选其一：

- **最省事**：点右上角「使用原创悬疑示例」，直接进入下一步。
- **粘贴**：把短篇或某一章贴进文本框，建议 3,000～8,000 字。
- **长篇**：点「选择文件」导入 `.txt` / `.md`（UTF-8 或 GB18030，20 MiB 以内）。导入后先选一个焦点章节，上方会显示自动装配的上下文包（不超过 12,000 字，含所选章节前后各最多两个相邻片段）。可以先改焦点章节再继续。

点「提炼故事世界」，等待几秒。

### 2. 校对故事世界卡（02 / 故事世界卡）

AI 会列出核心人物、世界规则、原始剧情三张卡。这是草稿，不是结论：

- 改掉任何与原文不符的人物身份、动机或关系。
- 补上你认为不可违背的世界规则。
- 第一位人物会被当作你接管的主角，可以调整顺序。

确认无误后再往下走——只有你确认过的内容才会约束后续推演。

### 3. 选择分歧点

页面给出三个分歧候选，每个都说明"原来发生了什么"和"为什么值得换一种选择"。点开一个卡片选中它，顺手设定路线最大步数（4～12 步，默认 12；第 4 步起就可以随时生成回顾）。

点「从这里走向另一条路」。

### 4. 推进剧情（03 / 新剧情线）

每个回合的节奏是一样的：

1. 先读当前场景、当前已接受剧情和右侧的剧情状态（主角目标、处境、人物关系、风险、未解决冲突）。
2. 从三个建议行动里选一个，或者在输入框写下主角真正会做的事。
3. 看推演草案：场景、状态变化、推演依据都会单独标出，**此时还没有写入剧情**。
4. 三个处理方式：
   - **接受回合**：草案成为新的已接受剧情，进入下一回合。
   - **不符合角色？留一句修正意见**：填写后重做，例如"他不会主动撒谎，请保持这个底线"。
   - 顶部「选择轨迹 · 当前路线」随时回看每一次选择，鼠标悬停或点击节点可看完整行动与结果。

走到设定步数后自动进入回顾；也可以提前在阶段回顾里收尾。

### 5. 带走阶段回顾（04 / NEW TIMELINE）

回顾页给出：

- 阶段剧情梗概；
- 按你的选择一路续写出来的路线结局，以及每个选择如何抵达结局；
- 偏离原始剧情之处、人物与关系变化、仍未解决的冲突、始终遵守的事实。

三个按钮：

- **继续这条故事线**：回到当前路线继续推演。
- **复制 Markdown**：把整份回顾复制走，用于后续写作。
- **推演另一段故事**：清空当前会话，从头导入新的故事。

## 常见情况

| 现象 | 说明 |
| --- | --- |
| 顶部显示"本地假模型" | 固定假数据，用于开发和自动化测试，不代表真实模型能力。真实评审请使用"真实模型"部署。 |
| 刷新后提示原文需要重新导入 | 长篇原文只存在于当前页面内存，不写入浏览器存储，也不整体上传。 |
| 模型输出不合法或超时 | 页面会提示失败并允许重试，此时剧情状态不会被写入。 |
| 想清空进度 | 点顶栏「重新开始」，会清除本地会话。 |

## 边界

- 不做全书语义理解与摘要：长篇只靠你选定的焦点章节和有界上下文包。
- 不做无限回合、不做场景图片、不做账号与云端项目、不做公开分享与完整分支树。
- 不承诺模仿特定文风。
- 故事原文与生成内容会发送到部署方配置的模型服务；模型密钥只存在服务端。
