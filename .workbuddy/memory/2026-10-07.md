# 2026-10-07

## Cloudflare 部署后仍显示"本地假模型"排查

- 根因：`lib/model-gateway.ts` 用 `process.env.STORY_MODEL_MODE?.trim() || "fake"` 决定模式，`.env.local` 只对本地 `next dev` 生效，不会被 OpenNext 打进 Worker 产物；`wrangler.jsonc` 当时也没有 `vars`，所以线上环境变量为空 → 回落fake。
- 修复：在 `wrangler.jsonc` 增加 `vars`（`STORY_MODEL_MODE=live`、`STORY_MODEL_BASE_URL=https://api.deepseek.com/v1`、`STORY_MODEL_NAME=deepseek-flash`、`STORY_MODEL_TIMEOUT_MS=90000`）。API Key 与可选的 `DEMO_ACCESS_CODE` 仍走 `wrangler secret put`。
- README 补充：线上模式由 `wrangler.jsonc` vars + Cloudflare secret 决定，可用 `/api/health` 的 `modelMode` 字段自检。
- 本机 `wrangler` 登录 token 已过期，部署前需交互式 `wrangler login` 或设置 `CLOUDFLARE_API_TOKEN`（当前环境非交互，无法代跑）。
- 项目 `.env.local` 当前为 live 模式，模型为 DeepSeek（base `https://api.deepseek.com/v1`，模型名 `deepseek-flash`）。
